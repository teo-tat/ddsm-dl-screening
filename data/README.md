# Data Directory

## Dataset

CBIS-DDSM (Curated Breast Imaging Subset of DDSM)  
Source: The Cancer Imaging Archive (TCIA)  
URL: https://www.cancerimagingarchive.net/collection/cbis-ddsm/

---

## What to Download

| File | Location | Size |
|---|---|---|
| Mass-Training Full Mammogram Images (DICOM) | `data/raw/mass_train/images/` | ~50GB |
| Mass-Test Full Mammogram Images (DICOM) | `data/raw/mass_test/images/` | ~10GB |
| Mass-Training ROI and Cropped Images (DICOM) | `data/raw/mass_train_roi/images/` | ~6GB |
| Mass-Test ROI and Cropped Images (DICOM) | `data/raw/mass_test_roi/images/` | ~2GB |
| mass_case_description_train_set.csv | `data/raw/` | <1MB |
| mass_case_description_test_set.csv | `data/raw/` | <1MB |

Calcification cases are excluded from this project — different pathology type, out of scope.

---

## Structure

```
data/
├── raw/
│   ├── mass_case_description_train_set.csv   # download from TCIA
│   ├── mass_case_description_test_set.csv    # download from TCIA
│   ├── mass_train/
│   │   └── images/         # 1231 patient-view folders — full mammograms
│   ├── mass_test/
│   │   └── images/         # 361 patient-view folders — full mammograms
│   ├── mass_train_roi/
│   │   └── images/         # ROI masks and cropped images — used for Grad-CAM validation
│   └── mass_test_roi/
│       └── images/         # ROI masks and cropped images — used for Grad-CAM validation
└── processed/              # Will be generated by src/data_loader.py
```

### Folder naming convention

Each patient-view folder follows the pattern:

```
Mass-{Split}_P_{PatientID}_{Side}_{View}/
└── {SeriesUID}/
    └── 000000.dcm
```

Example: `Mass-Training_P_00001_LEFT_CC/1.3.6.1.4.../000000.dcm`

---

## Notes

- All data files are excluded from version control via `.gitignore`
- Everything in this directory must be downloaded from TCIA before running the pipeline
- Processed files will be generated by running `src/data_loader.py`
- Patient-level splits are applied during processing, not during download
